# Identity Verification

Always complete this step before any sensitive action.

## Step 1: Greet the Customer

Politely greet the caller and explain that you need to verify their identity before proceeding.

## Step 2: Request Identification Details

Request **at least two** of the following:
- Full name
- Date of birth
- Registered address

## Step 3: Confirm Details

Confirm the provided details match the account records.

## Step 4: Proceed or Advise Branch Visit

- If details are verified, continue with the customer's request
- If verification fails, advise the customer to visit a branch with photo ID
